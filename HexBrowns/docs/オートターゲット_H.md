# オートターゲット_H / 座標公開_H

カメラ制御の目標を、指定したレイヤーのオブジェクトへ自動で合わせるカメラ効果です。ターゲットを複数並べて、
「ターゲット」の値を動かすと、カメラがターゲットからターゲットへ移ります。

- **オートターゲット_H**（`Script/オートターゲット_H.cam2`）… カメラ制御に掛けるカメラ効果
- **座標公開_H**（`Script/座標公開_H.anm2`）… ターゲットに掛けるフィルタ効果。「座標」などの効果で動かした後の位置をカメラへ渡す

どちらも v1.13。本体 2.1.10 以降（シーンオブジェクトを使う作品は 2.1.11 以降。下の「注意」）。**2 本は同じ版をそろえて使います。**

## インストール

1. `Script\オートターゲット_H.cam2` と `Script\座標公開_H.anm2` を配置する
2. AviUtl2 を再起動する
3. カメラ制御に「オートターゲット_H」を、ターゲットにしたいオブジェクトに「座標公開_H」を追加する（どちらも HexScript の中）

## 使い方

### 標準描画の位置を追う（座標公開_H は要らない）

1. カメラ制御を置き、追いたいオブジェクトを配下に入れる
2. カメラ制御に「オートターゲット_H」を追加する
3. **ターゲット1** に、追いたいオブジェクトのレイヤー番号を入れる
4. **座標モード** は「基準のみ」のまま

カメラは、そのオブジェクトの**標準描画の X / Y / Z と回転**を見ます。標準描画のトラックで動かしている限り、これで追います。

### 効果で動かした位置を追う（座標公開_H を使う）

「座標」「振動」などのフィルタ効果や移動スクリプトで動かしたオブジェクトは、標準描画の値が変わらないので、
「基準のみ」では追えません。

1. 追いたいオブジェクトの効果の**いちばん下**に「座標公開_H」を追加する（それより上の効果で動かした位置が渡る）
2. オートターゲット_H の **座標モード** を「世界座標」にする

座標公開_H は、グループ制御に掛けても使えます。そのときは配下のオブジェクトごとに、そのレイヤー番号で位置を渡します
（ターゲットには配下のオブジェクトのレイヤー番号を入れる）。

### ターゲットを渡り歩く

1. **ターゲット1〜10** に、順番に回りたいレイヤー番号を入れる
2. **ターゲット** のトラックを 1 → 2 → 3 … と動かす（中間点を打って直線移動など）

「ターゲット」が 1.5 ならターゲット1 と 2 の間を向きます。移り方は **イーズ** と **なめらか** で変わります。

## パラメータ

### オートターゲット_H

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| ターゲット | 1 ~ 100 | 1 | 何番目のターゲットを向くか。小数は前後のターゲットの間 |
| カメラ距離 | 0 ~ 20000 | 1024 | 目標からカメラまでの距離 |
| イーズ | 0 ~ 100 | 20 | ターゲットの間を移るときの緩急。0 で等速、大きいほど両端でゆっくり |
| なめらか | ON / OFF | ON | ON は前後のターゲットも使って曲線で移る。OFF は 2 つの間を直線で移る |
| 指定方法 | 絶対値 / カメラからの相対値 / 前ターゲットからの相対値 | 絶対値 | ターゲットの番号の意味。絶対値はレイヤー番号そのもの、カメラからの相対値はカメラ制御のレイヤー + 番号、前ターゲットからの相対値は 1 つ前のターゲットからの差 |
| 座標モード | 基準のみ / 世界座標 | 基準のみ | 基準のみは標準描画の値だけを見る。世界座標は座標公開_H が渡した位置を使う（無ければ標準描画） |
| ターゲット一覧 | 配列 | 空 | `{3,5,7}` のように書くと、ターゲット1〜10 の代わりに使う（11 個以上も並べられる） |
| ターゲット1〜10 | 0 ~ 1000 | 0 | ターゲットのレイヤー番号（指定方法が絶対値のとき） |
| PI | 表 | 空 | 設定の上書き（下の「PI」） |

**カメラの向き**: カメラは目標から「カメラ距離」だけ離れ、**ターゲットの回転に合わせて回り込みます**。
ターゲットが回っていなければ、正面（手前）から見ます。

### 座標公開_H

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 中心を含める | ON / OFF | ON | ON なら、オブジェクトの中心（回転の中心）の X / Y / Z の分も位置に含める |
| PI | 表 | 空 | 設定の上書き（下の「PI」） |

### PI

**オートターゲット_H** で上書きできるもの: `track_target_index`（ターゲット）、`camera_distance`、`easing`、`check_smooth`、
`target_set_method`、`coord_mode`（0 = 基準のみ / 1 = 世界座標）、`targets`、`tar1`〜`tar10`。
`world` にレイヤー番号ごとの位置を入れると、座標公開_H より優先して使います（例 `world={[3]={x=100,y=0,z=0}}`）。

**座標公開_H** で上書きできるもの: `include_center`、`layer`（渡すときのレイヤー番号を変える）。

## 注意

- **世界座標では 1 フレーム遅れて追います。** カメラ効果は、同じフレームのオブジェクトより先に計算されるためです。
  カメラが見るのは、座標公開_H が 1 つ前のフレームに渡した位置です。速く動くターゲットほど、画面の中心から少しずれます。
  座標公開_H を掛けたオブジェクトの最初のフレームは、まだ位置が届いていないので、標準描画の位置を見ます
- **プレビューでも出力と同じ絵になります**（v1.12）。← キーで戻っても、同じフレームを描き直しても、
  1 つ前のフレームを一度でも描いていれば出力と同じ位置を向きます。
  離れたフレームへ飛んだ直後だけは、隣のフレームをまだ描いていないと標準描画の位置を見ます。1 フレーム動かすか描き直すと追います
- 座標公開_H を外した・オブジェクトが終わった後は、1〜2 フレームのうちに標準描画の位置へ戻ります
- ターゲット1〜10 のうち使わない欄は 0 のままにし、「ターゲット」はその範囲を越えないように動かします
  （0 はレイヤー 1 を指す扱いになります）
- 「座標公開_H」のレイヤー番号は、効果を掛けたオブジェクトのレイヤーです。グループ制御に掛けたときも、配下のオブジェクトのレイヤーになります
- **シーンオブジェクトで別のシーンを描いても、位置は混ざりません**（v1.13、本体 2.1.11 以降）。
  カメラは、自分と同じシーンの座標公開_H の位置だけを見ます。v1.12 までは、別のシーンの同じレイヤー番号に座標公開_H があると
  位置が混ざり、標準描画の位置へ飛ぶことがありました。本体 2.1.10 では、この区別ができず v1.12 と同じ動きになります
- 版をそろえてください。v1.13 と v1.12 を組み合わせると、位置の受け渡しの形が合わず、カメラは標準描画の位置を見ます
