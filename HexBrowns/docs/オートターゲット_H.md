# オートターゲット_H / 座標公開_H

カメラ制御の目標を、指定したレイヤーのオブジェクトへ自動で合わせるカメラ効果です。ターゲットを複数並べて、
「ターゲット」の値を動かすと、カメラがターゲットからターゲットへ移ります。

- **オートターゲット_H**（`Script/オートターゲット_H.cam2`）… カメラ制御に掛けるカメラ効果
- **座標公開_H**（`Script/座標公開_H.anm2`）… ターゲットに掛けるフィルタ効果。「座標」などの効果で動かした後の位置をカメラへ渡す

どちらも v1.13。本体 2.1.10 以降で動きます。シーンオブジェクトを使う作品は 2.1.11 以降が必要です。
**2 本は同じ版をそろえて使います。**

## インストール

1. `Script\オートターゲット_H.cam2` と `Script\座標公開_H.anm2` を配置する。
2. AviUtl2を起動する。
3. カメラ制御に「オートターゲット_H」を、ターゲットにしたいオブジェクトに「座標公開_H」を追加する。どちらもHexScriptの中にある。

## 使い方

### 標準描画の位置を追う（座標公開_H は不要）

1. カメラ制御を置き、追いたいオブジェクトを配下に入れる。
2. カメラ制御に「オートターゲット_H」を追加する。
3. **ターゲット1** に、追いたいオブジェクトのレイヤー番号を入れる。
4. **座標モード** は「基準のみ」のまま。

カメラは、そのオブジェクトの**標準描画のX / Y / Zと回転**を見ます。標準描画のトラックで動かしている限り、これで追います。

### 効果で動かした位置を追う（座標公開_H を使う）

「座標」「振動」などのフィルタ効果や移動スクリプトで動かしたオブジェクトは、標準描画の値が変わらないので、
「基準のみ」では追えません。

1. 追いたいオブジェクトの効果の**いちばん下**に「座標公開_H」を追加する。それより上の効果で動かした位置が渡る。
2. オートターゲット_Hの **座標モード** を「世界座標」にする。

座標公開_Hは、グループ制御に掛けても使えます。そのときは配下のオブジェクトごとに、そのレイヤー番号で位置を渡します。
ターゲットには配下のオブジェクトのレイヤー番号を入れます。

### ターゲットを渡り歩く

1. **ターゲット1〜10** に、順番に回りたいレイヤー番号を入れる。
2. **ターゲット** のトラックを 1 → 2 → 3 … と動かす。

「ターゲット」が 1.5 ならターゲット1 と 2 の間を向きます。移り方は **イーズ** と **なめらか** で変わります。

## パラメータ

### オートターゲット_H

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| ターゲット | 1 ~ 100 | 1 | 何番目のターゲットを向くか。小数は前後のターゲットの間 |
| カメラ距離 | 0 ~ 20000 | 1024 | 目標からカメラまでの距離 |
| イーズ | 0 ~ 100 | 20 | ターゲットの間を移るときの緩急。0 で等速、大きいほど両端でゆっくり |
| なめらか | ON / OFF | ON | ONは前後のターゲットも使って曲線で移る。OFFは 2 つの間を直線で移る |
| 指定方法 | 絶対値 / カメラからの相対値 / 前ターゲットからの相対値 | 絶対値 | ターゲットの番号の意味。絶対値はレイヤー番号そのもの、カメラからの相対値はカメラ制御のレイヤー + 番号、前ターゲットからの相対値は 1 つ前のターゲットからの差 |
| 座標モード | 基準のみ / 世界座標 | 基準のみ | 基準のみは標準描画の値だけを見る。世界座標は座標公開_Hが渡した位置を使い、無ければ標準描画を見る |
| ターゲット一覧 | 配列 | 空 | `{3,5,7}` のように書くと、ターゲット1〜10 の代わりに使う。11 個以上も並べられる |
| ターゲット1〜10 | 0 ~ 1000 | 0 | 指定方法が絶対値のときは、ターゲットのレイヤー番号 |
| PI | 表 | 空 | 設定の上書き |

**カメラの向き**: カメラは目標から「カメラ距離」だけ離れ、**ターゲットの回転に合わせて回り込みます**。
ターゲットが回っていなければ、正面から見ます。

### 座標公開_H

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 中心を含める | ON / OFF | ON | ONなら、オブジェクトの中心X / Y / Zの分も位置に含める |
| PI | 表 | 空 | 設定の上書き |

### PI

**オートターゲット_H** で上書きできるもの: `track_target_index`、`camera_distance`、`easing`、`check_smooth`、
`target_set_method`、`coord_mode`、`targets`、`tar1`〜`tar10`。
`track_target_index` は「ターゲット」です。`coord_mode` は 0 が基準のみ、1 が世界座標です。
`world` にレイヤー番号ごとの位置を入れると、座標公開_Hより優先して使います。例: `world={[3]={x=100,y=0,z=0}}`

**座標公開_H** で上書きできるもの: `include_center`、`layer`。
`layer` は渡すときのレイヤー番号を変えます。

## 注意

- **世界座標では 1 フレーム遅れて追います。** カメラ効果は、同じフレームのオブジェクトより先に計算されるためです。
  カメラが見るのは、座標公開_Hが 1 つ前のフレームに渡した位置です。速く動くターゲットほど、画面の中心から少しずれます。
  座標公開_Hを掛けたオブジェクトの最初のフレームは、まだ位置が届いていないので、標準描画の位置を見ます
- **プレビューでも出力と同じ絵になります**。← キーで戻っても、同じフレームを描き直しても、
  1 つ前のフレームを一度でも描いていれば出力と同じ位置を向きます。
  離れたフレームへ飛んだ直後だけは、隣のフレームをまだ描いていないと標準描画の位置を見ます。1 フレーム動かすか描き直すと追います
- 座標公開_Hを外した・オブジェクトが終わった後は、1〜2 フレームのうちに標準描画の位置へ戻ります
- ターゲット1〜10 のうち使わない欄は 0 のままにし、「ターゲット」はその範囲を越えないように動かします。
  0 はレイヤー 1 を指す扱いになります
- 「座標公開_H」のレイヤー番号は、効果を掛けたオブジェクトのレイヤーです。グループ制御に掛けたときも、配下のオブジェクトのレイヤーになります
- **本体 2.1.11 以降では、シーンオブジェクトで別のシーンを描いても、位置は混ざりません**。
  カメラは、自分と同じシーンの座標公開_Hの位置だけを見ます。
  本体 2.1.10 ではこの区別ができず、別のシーンの同じレイヤー番号に座標公開_Hがあると、位置が混ざって標準描画の位置へ飛ぶことがあります
- 版をそろえてください。v1.13 と v1.12 を組み合わせると、位置の受け渡しの形が合わず、カメラは標準描画の位置を見ます
