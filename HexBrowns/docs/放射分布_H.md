# 放射分布_H

掛けたオブジェクトをたくさん複製して、**中心から放射状に散らばりながら広がる**ように並べるフィルタ効果です。第三者作の `@tim.anm2.anm2` の「放射分布」を元にしています。

元と同じ位置・大きさ・回転・透明度で描き、**描き込む作業用の画像を、粒が届く範囲だけの大きさにして軽くしました**（元は常に画面いっぱい）。粒が全部消えたフレームでは何もしません。

## インストール

1. `Script\放射分布_H.anm2` を置く
2. AviUtl2 を再起動する（新しく置いたスクリプトは、再起動するまで一覧に出ません）
3. フィルタ効果の **HexScript → 放射分布_H** から追加する

## 使い方

1. 小さな図形や画像を置き、フィルタ効果「放射分布_H」を追加する
2. **個数** の分だけ複製が **初期半径** の円の中に散らばり、時間とともに **速度** で外へ広がる
3. オブジェクトの終わりに向かって、粒が順に消えていく（**消滅時間**・**消滅速度**）

## パラメータ

| パラメータ | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 速度 | 0 ~ 10000 px/秒 | 30 | 粒が外へ広がる速さ |
| 放射度 | 0 ~ 100 % | 100 | 中心からの距離に掛ける割合。0 で中心に集まる |
| 初期半径 | 0 ~ 10000 px | 100 | 最初に粒が散らばる円の半径 |
| 個数 | 1 ~ 10000 | 30 | 粒の数 |
| 速度誤差 | 0 ~ 10 | 1.5 | 広がる速さの粒ごとのばらつき |
| 均等動径配置 | オン / オフ | オフ | オンで粒を初期半径の円周に並べる（オフは円の中に散らばる） |
| 均等角配置 | オン / オフ | オフ | オンで粒を等しい角度で並べる |
| 初期回転角誤差 | 0 ~ 360 ° | 360 | 粒の向きのばらつき |
| 最大回転速度 | 0 ~ 1000 | 45 | 粒が回る速さの最大 |
| 消滅時間 | 0 ~ 10 秒 | 0.3 | オブジェクトの終わりのこの時間の間に、粒が順に消え始める |
| 消滅速度 | 0 ~ 100 | 10 | 消え始めた粒が薄くなる速さ |
| 中心X / 中心Y | ±2000 px | 0 / 0 | 広がりの中心 |
| 乱数シード | 0 ~ 1000000 | 200 | 粒の並びを変える種 |

## 注意

- 元の「放射分布」から乗り換えると、項目名が同じなので、同じ値を入れれば同じ絵になります
- 粒の並びは乱数で決まり、同じ **乱数シード** でもオブジェクトごとに変わります
